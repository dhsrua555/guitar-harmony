# 기타 & 화성학

기타 코드 보이싱, 스케일 포지션, 릭과 화성학(인터벌, 코드, 스케일, 모드, 코드 진행, 리하모니제이션)을 보고 듣고 연습하는 정적 웹사이트입니다. 음감 퀴즈, 백킹트랙, 멜로디 → 코드 찾기 도구가 있고 빌드 도구는 필요 없습니다.

## 구조 (쉬운 것은 앞에, 어려운 것은 안쪽에)

- **홈**: 큰 제목과 검색창, 누르면 소리가 나는 오선 그림(노란 공이 음표 위를 튐), 세 갈래 번호 카드(01 배우기 / 02 코드 하나 찾기 / 03 연습), 섹션 전체 목록, 현재 키의 기본 코드(리드 시트)로 이어집니다.
- **배우기** `#/learn`: 6단계 로드맵. 기초(1~3) → 중급(4~5) → 심화(6).
- **기타 / 화성학 / 연습** 허브: 각 섹션의 페이지를 기초 · 더 깊이로 나눠 소개합니다. 페이지 안의 어려운 내용은 "심화" 접기 상자에 들어 있습니다.
- **가이드**: 처음 방문하면 음악 지식 수준과 목표를 묻고, 그에 맞는 미션을 쉬운 것부터 추천합니다. 수준·목표는 설정 › 나의 학습에서 언제든 바꿀 수 있고, 각 페이지 위의 사용법 상자는 같은 곳에서 끌 수 있습니다. 기록은 이 브라우저에만 저장됩니다.
- 휴대폰(가로 900px 이하)에서는 상단이 [MENU] [로고] [검색] 한 줄로 바뀌고, MENU 를 누르면 전체 화면 메뉴가 내려옵니다. 검색 버튼은 키 · 검색 · 설정 줄을 엽니다. 오른쪽 위의 빨간 "오늘의 연습" 탭은 가이드의 다음 미션으로 갑니다.
- 상단 왼쪽 ← 버튼이 앱 안의 뒤로가기입니다. 탭이나 필터를 바꾸는 이동은 히스토리에 쌓이지 않으므로 뒤로가기가 페이지 단위로 움직입니다.

## 열기

- 가장 간단한 방법: `index.html` 을 더블클릭해서 브라우저로 엽니다. (Chrome, Edge 권장)
- 로컬 서버로 열기: `serve.bat` 을 실행하면 `http://localhost:8080` 에서 열립니다. (Python 이 필요합니다.)
- 웹사이트: https://dhsrua555.github.io/guitar-harmony/ (GitHub Pages. main 브랜치에 올리면 1~2분 뒤 자동으로 바뀝니다.)
- Claude 아티팩트로 열기: https://claude.ai/artifact/SCJ4UAf3f8DcXpEMCz9JRD
- 오선 표기(VexFlow)는 인터넷에서 불러오므로 오프라인이면 TAB 만 표시됩니다. 나머지 기능은 전부 오프라인에서 동작합니다.

## 콘텐츠 추가하기

모든 콘텐츠는 `js/data/` 의 자바스크립트 파일에 있습니다. 파일을 고치고 새로고침하면 반영됩니다.

- **코드 타입** `js/theory/chords.js` 의 `QUALITIES`: id, 표기, 인터벌, 텐션, 어울리는 스케일. 구성별 분류(`CATEGORY_OF`)와 난이도(`LEVEL_OF`)도 같은 파일에서 정합니다.
- **백킹트랙 스타일** `js/audio/backing.js` 의 `STYLES`: 드럼 이벤트(박 단위), 컴핑 패턴, 베이스 패턴 이름.
- **스케일 / 모드** `js/theory/scales.js` 의 `SCALES`, 모드 부가 정보는 `js/data/modes.js`.
- **코드 폼** `js/data/voicingShapes.js`: `S(코드타입, 유형, 이름, '프렛', '손가락', 기준줄, 기준인터벌)`. 프렛은 6번줄부터, `x` 는 뮤트. 무버블 폼은 기준줄의 음이 기준 인터벌이 되도록 자동으로 이동합니다. 드롭 2/3, 트라이어드는 자동 생성되므로 적을 필요가 없습니다.
- **코드 진행** `js/data/progressions.js`: 로마 숫자 배열 (`'ii7'`, `'V7'`, `{ r: 'I', beats: 2 }`, `'V7/ii'`, `'I/3'`, `'bVII7'`, `'#iv°7'`). 마이너 키는 `mode: 'minor'`.
- **릭** `js/data/licks.js`: `n(줄, 프렛, 박, 기법)` 이벤트 배열. 더블스톱은 `ns: [[줄, 프렛], ...]`, 코드 변경은 `ch: 'G7'`.
- **리하모니 기법** `js/data/reharm.js`, **곡 분석** `js/data/songs.js`, **용어** `js/data/glossary.js`.

데이터를 고친 뒤 `dev/check.html` 을 열면 잘못된 폼, 파싱 안 되는 로마 숫자, 범위를 벗어난 릭 음을 알려 줍니다.

## 표기 규칙

- 인터벌 이름: `1 b2 2 b3 3 4 #4 b5 5 #5 b6 6 bb7 b7 7 b9 9 #9 11 #11 b13 13`
- 색: 루트 빨강, 3음 파랑, 5음 초록, 7음 주황, 텐션 보라, 그 밖의 스케일 음 회색
- 코드 심볼: 표준 표기(Cmaj7, Dm7, Bm7b5)가 기본, 설정에서 재즈 약식(C△7, D-7, Bø7)으로 전환
- 난이도: 셈여림 기호로 표시합니다. p 기초, mf 중급, ff 고급. 릭 난이도는 음표 다섯 개 중 채워진 수입니다.
- 심화 접기 상자: ♯ 을 누르면 펼쳐지고, 펼쳐지면 ♮ 로 바뀝니다.

## 디자인

- 글꼴 (모두 Google Fonts): 제목 Black Han Sans · Bayon, 본문 Noto Sans KR, 코드 심볼 Kalam, 악보 제목 · 스타일 표기 Permanent Marker (한글은 Gaegu), 임시표 기호 Noto Music.
- 악보는 리얼북처럼 그립니다. 음표와 음자리표는 VexFlow 에 들어 있는 손글씨 글꼴 Petaluma, 마디 위 코드 심볼은 손글씨, 왼쪽 위에 `(Med. Swing) ♩ = 120` 같은 스타일 표기, 마지막 마디는 끝세로줄. 종이 색은 다크 테마에서도 밝게 둡니다.
- 색 토큰은 `css/style.css` 맨 위 `:root` 와 `:root[data-theme="dark"]` 에 있습니다. 브랜드 빨강(`--brand`)은 근음 색(`--iv-1`)과 구분되게 주황 쪽이고, 인터벌 색은 크림 배경에서도 서로 구분되도록 맞췄습니다.
- 움직임: 스크롤하면 섹션이 떠오르고, 배우기 로드맵 카드는 넓은 화면에서 스크롤할 때 차곡차곡 쌓입니다. 운영체제의 "움직임 줄이기" 설정을 켜면 인트로 · 흐르는 띠 · 떠오르기 · 튀는 공이 모두 꺼집니다.
- 그림은 잉크로 그린 삽화처럼 보이게 합니다. 선은 두 번 겹쳐 긋고 조금씩 휘며, 음 동그라미는 칠이 선에서 살짝 어긋나고, 검은 건반과 히어로 그림에는 빗금 그림자가 들어갑니다. 위에는 인쇄 종이 같은 알갱이가 한 겹 얹힙니다. 아이콘과 히어로 그림은 마우스를 올리면 선이 끓어오르듯 흔들립니다 (움직임 줄이기 설정이면 멈춤). 분위기 참고: 2019.makemepulse.com.
- 숫자로 고르는 값(템포, 박자, 마디 수, 최대 프렛, 카포, 코드 수 등)은 드롭다운 대신 직접 적는 칸입니다. − / + 버튼을 누르고 있으면 계속 바뀌고, 범위를 벗어난 값은 가장 가까운 값으로 맞춰집니다.
- 외부 사이트의 로고 · 이미지 · 문구는 쓰지 않았습니다. 그림은 전부 이 저장소의 인라인 SVG 입니다.
- 코드 폼은 스탠다드 튜닝 기준. 다른 튜닝은 스케일 프렛보드에만 적용됩니다.
- 소리: 기타 · 피아노 · 베이스 · 드럼은 실제 악기 녹음(CC BY 3.0 / CC0, 출처는 `audio/samples/CREDITS.md`)으로 냅니다. 지금 고른 악기와 베이스만 받고, 드럼(1.3MB)과 콘트라베이스(1.7MB)는 백킹 트랙에서만 받습니다. 스윙 · 보사노바는 콘트라베이스, 나머지 그루브는 일렉 베이스입니다. 드럼은 세기 층과 라운드로빈(같은 세기의 다른 타격)을 골라 쓰고, 하이햇을 닫으면 열린 하이햇 소리가 끊깁니다. 받는 동안이나 설정에서 '합성음 (데이터 절약)'을 고르면 합성음으로 냅니다.
- 지판은 22프렛까지 표시하며, 지판 · 건반 · 코드 다이어그램의 음을 누르면 소리가 납니다.
- 백킹트랙 코드 입력: `Dm7 G7 | Cmaj7 | Am7 D7` 처럼 세로줄로 마디를 나눕니다. 세로줄이 없으면 코드 하나가 한 마디입니다.
